# Farmwise360 - Frontend

Farmwise360 is an intelligent agricultural advisory application powered by Next.js and AI, designed to assist farmers with real-time weather analytics, personalized crop suggestions, and interactive voice and multimodal assistance.

## Key Features

- **Interactive AI Assistant (Robot Interface)**: Real-time intelligent agricultural advisor with interactive voice listening overlay and modal responses.
- **Dynamic Weather Intelligence**: Comprehensive weather overview modal and page view with real-time temperature, humidity, wind, and forecast conditions.
- **Smart Crop Advisory**: Actionable crop management recommendations and disease/pest detection suggestions.
- **Location & Settings Personalization**: Multi-language support, custom farm profiles, and geolocation customization.
- **Modern Responsive Design**: Built with Next.js App Router, Tailwind CSS utilities, Lucide icons, and responsive layouts.

## Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm, yarn, or pnpm

### Installation

```bash
cd frontend
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Building for Production

```bash
npm run build
npm run start
```
